# Support

kube-shield is easiest to support when reports are concrete and sanitized. Use the channel that matches the kind of help you need.

## Where To Ask

- Bugs: open a GitHub issue with reproduction steps and environment details.
- Feature requests: open a GitHub issue describing the workflow or security gap.
- Usage questions: open an issue marked as a question if GitHub Discussions are unavailable.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Make Reports Actionable

Please include:

- kube-shield version from `kube-shield version`.
- Kubernetes version and distribution, if relevant.
- Install method: Homebrew, Go, Docker, Helm, release archive, or source build.
- Exact command and flags used.
- Sanitized config, manifest snippets, and output.
- Whether the issue reproduces with `--output json`.

Do not include real tokens, kubeconfig credentials, API keys, secret values, private cluster names, or customer-identifying data.
