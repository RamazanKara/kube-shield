kube-shield has been installed.

To verify the CronJob:

  kubectl get cronjob -l app.kubernetes.io/name={{ include "kube-shield.name" . }}

To run a manual scan:

  JOB=kube-shield-manual-$(date +%s)
  kubectl create job --from=cronjob/{{ include "kube-shield.fullname" . }} "$JOB"

To inspect scan output:

  kubectl logs "job/$JOB"

Secret checks use Kubernetes Secret metadata by default. The chart grants only list on core
secrets so missing references can be validated, and kube-shield does not request full Secret
objects unless readSecretData=true is set for the SEC-010 empty-secret check.

For more information, visit: https://github.com/RamazanKara/kube-shield
